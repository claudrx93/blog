使用 HTML 进行打印时，常常需要设置页面属性，那么 `@page` 的设置就是 CSS3 带来的属性。

工作中遇到需要设置页边距的问题，但是发现一直不生效。

## 问题代码

```css
@page {
  size: 70mm 40mm portrait;
  margin: 5mm 0mm 0mm 0mm;
}
```

## 原因

经过测试发现，设置了页边距后，页边距只有在**默认**的情况下会生效，一旦设置了无边距或者自定义打印设置，则会覆盖网页的 `@page` 设置。

这是一个较小的问题，但是对于不熟悉的人可能会调试到抓狂。
