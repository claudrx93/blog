PHP 的变量是带上 `$` 的，但是 VSCode 双击选择时是不带上 `$` 的，所以在快速选择时总是会造成不便。

强大的 VSCode 自然是可以通过配置解决问题的。

## 解决方法

在设置上搜索 `wordSeparators`，原来这个是归**分词功能**管的。

找到这个选项，把里面的 `$` 删除则可。

## 修改前

默认 `wordSeparators` 包含：

```
`~!@#$%^&*()-=+[{]}\|;:'",.<>/?
```

## 修改后

删除 `$`：

```
`~!@#%^&*()-=+[{]}\|;:'",.<>/?
```

现在双击 PHP 变量名时，`$variable` 会被完整选中。
